# 全站玻璃质感统一（2026-10-23 夜）

## 目标
导航栏 / 侧栏面板 / 内容卡片 / 所有 antd 弹窗与浮层使用同一套 iOS 磨砂玻璃，消除「玻璃卡片 + 纯白弹窗」的断层。

## 必然要做的四件事

### 1) 补齐 antd 主题（src/App.tsx）
顶层包 `ConfigProvider`，`theme={{ cssVar: true, hashed: false, token: {...}, components: {...} }}`：
- token：`colorBgContainer rgba(255,255,255,0.62)`、`colorBgElevated rgba(255,255,255,0.82)`、`colorBorder rgba(255,255,255,0.72)`、`borderRadiusLG 20`、`boxShadow 0 20px 60px rgba(15,23,42,0.08)`
- components：Modal(contentBg 0.82 / headerBg transparent)、Table(headerBg 0.55 / rowHoverBg 0.45)、Dropdown(0.82)、Select(selectorBg 0.62)
- `hashed: false` 让 token 以稳定 CSS 变量输出，覆盖不会被 hash 类名打断

### 2) antd 浮层补 backdrop-filter（新增 src/styles/glass-antd.css，main.tsx 在 index.css 之后引入）
选择器（每条同时写 `-webkit-` 与标准属性 + `!important`）：
`.ant-modal-content`、`.ant-modal-mask`、`.ant-dropdown-menu`、`.ant-select-dropdown`、`.ant-picker-panel-container`、`.ant-table-thead>tr>th`、`.ant-message-notice-content`、`.ant-popover-inner`、`.ant-drawer-content`
- 模糊 `blur(20px) saturate(180%)`、边框 `1px solid rgba(255,255,255,0.35)`、投影 `0 8px 32px rgba(31,38,135,0.12)`
- 遮罩 `.ant-modal-mask`：`rgba(15,23,42,0.28)` + `blur(2px)`，替换 antd 默认纯黑半透明
- 浮层底色显式写 `rgba(255,255,255,0.82)`（表头 0.55），不依赖 token 求值时机
- `@supports not (backdrop-filter)` 降级：底色 `rgba(255,255,255,0.92)`、去掉模糊

### 3) 修掉会杀死 backdrop-filter 的祖先链
- `PredictionModule.tsx` 名称弹窗：去掉玻璃元素自身的 `animate-fade-in`（该类此前根本不存在，属无效类）
- `UserProfile.tsx`：删掉包裹玻璃卡片的 `animate-fade-in`（祖先带动画 = 新建 backdrop root）
- `ImageManagement.tsx` 图片卡片：去掉 `transform hover:-translate-y-1`；卡片内悬浮的圆形/方形按钮由玻璃改为 `bg-white/90`（它们处在 `opacity-0 + scale-0` 覆盖层里，玻璃必然失效）
- `index.css`：`.glass-panel:hover` 只改透明度，上浮改为可选类 `.glass-lift`（全局 hover 上浮会给自己造 transform，反而杀掉子级玻璃）
- `EditImageModal.tsx`、`ImageManagement.tsx`、`PermissionManagement.tsx`、`PredictionModule.tsx`、`UserPermissionEditor.tsx`：自定义弹窗蒙层由 `bg-black/50 backdrop-blur-sm` 统一为 `bg-[rgba(15,23,42,0.28)] backdrop-blur-[2px]`

### 4) 清理不透明底色
一次性脚本（网页/run_logs/glassify.cjs）按 className 上下文判定后替换，共 213 处、涉及 18 个 tsx：
- 卡片/面板 `bg-white` → `glass-panel`
- 小胶囊 `bg-white rounded-full` → `glass-pill`
- 次级块 `bg-slate-50 / bg-gray-50 / bg-slate-100` → `glass-panel-soft`
- 表单控件（含 `outline-none` / `focus:`）→ `bg-white/55`、`bg-white/45`，不再写死纯白
- `hover:bg-slate-50 / hover:bg-gray-50 / hover:bg-gray-100` → `hover:bg-white/45`；`hover:bg-white` → `hover:bg-white/70`；`focus:bg-white` → `focus:bg-white/80`
- 玻璃串里多余的 `border-slate-200 / border-gray-200` 一并删除（glass-panel 自带边框）
- 替换后全仓 `bg-white`（不带透明度）/`bg-gray-50`/`bg-slate-50`/`bg-slate-100` 计数为 **0**

## 背景层加强（src/index.css）

## 第二轮：看图后的实际修正（2026-10-24 凌晨）
可以读图 / 打开浏览器后，逐页截图复核（截图 网页/run_logs/glass-shots/look-*.png），发现并修掉 6 类观感问题：

1. **预测页四个统计块是纯色大色块**（绿/蓝/紫/橙实心渐变），与"不要随便上色"冲突
   → `PredictionModule.tsx` 改为玻璃卡 + 12% 透明度的 iOS 系统色图标胶囊（蓝 #0a84ff / 靛 #5856d6 / 紫 #af52de / 橙 #c2740a），文字改深色。
2. **图片管理的按钮是饱和绿**（新建文件夹、上传图片/文件夹、创建），标题是绿蓝渐变文字
   → 全部改 iOS 蓝实心按钮 `bg-[#0a84ff]` + hover `#0070e0` + active 缩放；标题改 `text-slate-900`；侧栏从 `from-green-50 to-white` 改 `bg-white/45 backdrop-blur-xl`。
3. **预测页整片绿**（全选按钮、复选框、滑块轨道、focus ring、主按钮、命名弹窗确认键）
   → 统一为 iOS 蓝；`PredictionModule.tsx` 里 `green` 出现次数归零。
4. **结果中心**：结果卡按病害程度整张染成粉/黄/绿 + 三颗实心蓝导出按钮 + 指标卡被拉成 270px 高
   → 卡片改中性玻璃，严重程度改用卡片标题前 1.5px 彩色圆点；导出按钮改玻璃幽灵按钮；指标卡 `self-start` 收成 24px 数字高；健康分布卡间距压缩一半。
5. **首页主视觉文案对比度不足**（`text-slate-300/400` 压在蓝紫渐变上）+ 四张特性卡"发虚"
   → 文案改 `text-white/90`、`text-white/75`，主按钮改纯白底深字；`--glass-shadow` 增加 `0 0 0 1px rgba(15,23,42,0.05)` 发丝描边，让浅底上的玻璃卡有边界。
6. **任务中心只有 1 条任务时，列表被拉成一整屏灰色空壳**
   → 列表卡从 `flex-1` 改 `max-h-full`（内容少时贴内容），底部加"已经到底了"（新增 `tasks.list_end` 文案）。

顺带修掉的脏数据样式：`bg-white/40/70`、`bg-white/40/80`、`hover:bg-white/45/80` 这类非法叠加（批量替换产生的）共 5 处，涉及 ContactUs.tsx、PermissionManagement.tsx、TaskCenter.tsx。

回归结果：`tsc --noEmit` 0 错；`vitest run` 8 文件 23 项全过；`vite build` 成功；八页扫描「纯白无模糊元素 0、玻璃祖先链违规 0」；真实 TreeSelect 下拉仍为 `rgba(255,255,255,0.82) + blur(20px) saturate(1.8)`。
