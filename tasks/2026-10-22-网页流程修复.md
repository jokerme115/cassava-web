## 实际修复

### 流程与路由
- `App.tsx` 有 BrowserRouter 但页面用 useState 切，地址栏不跟着变。改为 `src/components/CassavaApp.tsx` 由 `useLocation` 派生 activeSection，模块级 `KNOWN_SECTIONS` / `sectionFromPath` / `pathFromSection`，所有跳转改 `navigate()`；新增深链接守卫（未登录访问受保护页 → `setPendingSection` + `/login`，登录后回原页）。
- 维护模式原先在 renderContent 前直接 return，管理员登录按钮点不动。现维护页放行 `activeSection === 'login'`，管理员仍可登录。
- 记住我原本是死代码（只写 sessionStorage.freshLogin）。新增 `src/utils/authToken.ts`（`getAuthToken` 读 localStorage‖sessionStorage、`setAuthToken(token, remember)`、`clearAuthToken`），`services/api.ts` 拦截器与 `LoginPage.tsx` 全部改用它。
- `auth:expired` 原先丢失待返页面；现在 `activeSectionRef` 记录当前页，过期后登录可回原页。
- 访客登录原先只在前端伪造 `{id:0,is_guest:true}`，刷新即丢。后端新增 `predict/auth_views.py::guest_session` + `predict/urls.py:53 path('auth/guest/')`，用 `secrets.token_urlsafe(32)` 签发标识；前端新增 `src/utils/guestSession.ts`，`api.ts` 发 `X-Guest-Token`，`CassavaApp.tsx` 无 token 时用 `loadGuestSession()` 恢复身份，退出时 `clearGuestSession()`。

### 预测与任务
- 模型统一改名：`predict/ensemble.py:5 LABELS`、`predict/result_export.py:20` 表头、`predict/services.py:1635` 报错文案；前端 `src/utils/modelLabels.ts` 做显示名映射并兼容历史 V1.0/V1.1。内部 key（resnet101 / m6_best / ensemble）不变。
- 预测页选文件夹时摘要一直是“0 项 / 0 张图”，且只有一键按钮可用。`PredictionModule.tsx` 增加 `folderOnlySelection` / `summaryItemCount` / `summaryImageCount`，选中文件夹即显示「整个文件夹」并允许直接创建任务（`handleStartPrediction` 转调 `handleStartFolderPrediction`）。
- 一键提交整个文件夹：`buildTaskPayload` 统一两条路径，工具条新增 `prediction.submit_folder` 按钮。
- `useTaskStore.retryTask` 复用原任务参数重跑；任务中心新增 pending 排队徽标、已完成「查看结果」（`navigate('/results?task=' + id)`）、失败「重新执行」。
- 后端 `ProcessingTaskSerializer.queue_position` 返回 pending 队列序号（`serializers.py:315-323`，对未保存实例做了空值保护），前端 `types/index.ts` + `normalizeTask` 透出 `queuePosition`。
- 部分失败可见性：`predict/services.py:3492-3509` 在 completed 分支按 `execution['errors']` 写 `task.error`（“N 张图片未生成结果：…”并附前 3 条原因），前端任务卡与详情弹窗用 amber 提示展示，不再把部分失败当全成功。

### 结果中心与文案
- 结果中心英文混排（All Tasks / Loading... / records 等）改 i18n，新增 `results.*` 与 `common.loading` 键；`/results?task=123` 可直达聚焦某个任务。
- 加载页泄漏 `common.loading` 原始键的问题一并修掉。
- 任务用时异常（失败任务算出 2209 小时）：`TaskCenter.tsx` 的 `formatDuration` 增加 running 参数，非运行中且无结束时间直接显示 `--`。
- 登录页硬编码英文（SMART PLATFORM / AI Segmentation / Results Archive / Research Support / Account Access 与中文提示）改 `login.*` 键。
- `PredictionResultEditor.tsx` 三处 `window.confirm` 改为 antd `Modal.confirm`（统一 `confirmAction` 助手，Promise 化）。
- 删除无引用组件 `AppSidebar.tsx`（已获授权，备份 `网页/run_logs/AppSidebar.tsx.deleted-backup`）。

### 顺带修掉的实际缺陷
- 数据库缺列：`predict_cassavaimage.pixel_width` 未迁移，导致 `/api/images/` 500、预测页 0 张图。执行 `migrate predict 0037`（迁移前备份 `db.sqlite3.bak-20261022-pre-migrate`）。
- 单模型推理崩溃：`predict/services.py` 的 `predict_ppd` 在 `use_ensemble=False` 时仍走到 `raise ValueError('不支持的集成方法: pixel_vote_probability_tiebreak')`。补了“非集成直接用唯一输出”的分支。
- 访客打开页面报 401 `/api/system/settings/` 并被踢回登录：`useResultsStore.ts` / `useImageStore.ts` 访客走 `getPublic()`；`api.ts` 的 401 拦截器改为只有原本带 token 时才派发 `auth:expired`；`PredictionModule` 接收 `currentUser` 并把 isGuest 传给 `useImageStore`。
