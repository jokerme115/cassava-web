# 全站字体规范

采用 A 方案：中文使用思源黑体，英文与数字使用 Inter。字体随网页本地提供，不依赖系统安装或外部 CDN。思源黑体网页子集的内部名称为 Cassava Han Sans，原始来源、许可证与哈希见前端 public/fonts/PROVENANCE.json。

唯一配置入口为前端 src/theme/typography.json，Tailwind、Ant Design 和页面样式共用该配置。

| 用途 | 字号 | 行高 | 字重 |
| --- | --- | --- | --- |
| 辅助信息、图片元数据 | 13px | 20px | 400 |
| 按钮、表单、列表 | 14px | 22px | 400 / 500 |
| 正文 | 15px | 24px | 400 |
| 面板、弹窗标题 | 18px | 28px | 600 |
| 页面标题 | 24px | 34px | 600 |
| 重点数值 | 32px | 40px | 600 |
| 首页主标题 | 48px | 60px | 600 |

同一用途不随页面任意变换字号，不使用额外的 10px、11px 或装饰性衬线字体。仅保留两个明确的移动端适配：首页主标题为 32px；手机输入框为 16px。数字使用等宽数字形式，便于比较 PPD、数量和时间。

新增页面优先使用 page-title、section-title、body-text 和 metric-value 等语义样式；普通标题与内容使用对应的统一字号，不再添加临时字号。
