# 木薯网页版升级交付说明

本轮交付本地网页版，使用现有 CPU 环境。实施开始于 2026-10-29，验收收尾于 2026-10-30。未进行训练或线上发布。

## 启动与使用

在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Start-Local.ps1
```

访问 <http://127.0.0.1:5173/>。脚本启动前端、后端及独立导入 worker，并检查后端健康接口及前端代理。默认端口为 5173/8000；本地数据库、媒体、邮件与生产配置隔离。重启不会自动清除任务、图片或回收站。

### 图片与目录

1. 左侧目录树选择位置；顶部路径可返回上层。目录支持新建、改名和拖放移动。
2. 上传按钮旁显示目标路径。散图直接进入当前位置；“全部图片”沿用最近的可写目录，首次为未分类。
3. 文件夹或 ZIP/7Z/RAR 使用同一个归档面板，选择原名新建、自定义或已有目录，可保留内部层级。同名目录可在面板内复用；新建冲突默认自动编号。
4. 导入任务显示真实成功、跳过和失败数。支持打开目标目录、取消、仅重试失败项；刷新后用原文件或原目录续传。
5. 原文件字节 SHA-256 只在同一最终目录查重。同名不同内容保留并自动改名；父子目录及其他目录不参与查重。
6. 图片显示原始分辨率、EXIF 拍摄时间和时间来源；缺失显示未提供。选择一张或多张后可补填拍摄时间，服务端保留变更来源及历史。低分辨率提醒不阻止上传。
7. 删除进入回收站。恢复保留原记录 ID；永久清除必须查看关联图片、预测和修订影响并确认。日常删除不会移除历史预测及修订。

图片、任务、结果使用服务端筛选、分页及统计；图片提供选择全部符合条件的记录。目录、搜索、排序、分页和滚动位置在浏览器中按账号保存。列表最后一页失效后可自动返回有效页。

### 模型与复检

默认模型为 PBT SegFormer-B2 c512 五种子。另提供 HRNet-W48 seed101、Mask2Former Swin-T seed42、M6 fold1 历史部署版；c384 五种子为高级对照，历史模型继续兼容。前端从后端模型注册表获取可用性、版本及权重信息。

主模型串行在 CPU 上运行。冻结权重加载时核对 SHA-256；不因模型失败自动换模型，也不自动更改输入分辨率。未定位到有效切面会显示失败原因。

复检工具提供主体与病斑图层、画笔、橡皮、圈选、平移缩放、模型原预测对照、撤销重做和连续切图。较大的相机原图也可完整适应编辑区。

- 本机草稿：保存在当前浏览器，可在切图后恢复。
- 保存人工校正版本：新建服务端修订，不覆盖原预测和历史修订。
- 完成复检：绑定当前保存版本；允许确认无需修改。再次保存新修订后，必须重新完成复检。

多人同时保存会检查基础版本冲突。轮廓编辑按原尺寸二值掩码计算，内缩可减少面积，并保留未修改孔洞及小病斑。复检交互参考 [CVAT Shapes](https://docs.cvat.ai/docs/annotation/manual-annotation/shapes/)，没有引入整套 CVAT 服务。

### 导出

默认成图为主体青色轮廓、病斑粉红轮廓、白底 `PPD = xx.xx%`，不加标题、编号或图例。同一照片中的切面并排；也可跨照片拼图。

“自定义导出”可调整两层颜色、线宽、填充与透明度，以及字号、显示内容、列数、留白、单切面宽度，并保存个人模板。预览与图包使用同一个渲染函数。

默认选择最新保存修订，没有则采用模型预测。可选模型原预测；针对当前图片可选择历史修订。导出开始时固定版本快照，PNG、CSV、Excel 和 ZIP 清单使用同一份数值。

ZIP 内包括轮廓成图、原图、模型/最终掩码、叠加图、总表、切面明细及 `manifest.json`。清单记录模型、参数、修订版本、复检状态和样式。每个切面单独计算 PPD；整图按主体与病斑原尺寸像素计算，不平均各切面的百分数。

### 真实 CPU 推理

同一张 2268×4032 相机原图，检测到 3 个切面，分别经真实 HTTP 任务运行：

| 模型 | 任务 | 墙钟耗时 | 后端进程累计峰值内存 |
|---|---:|---:|---:|
| PBT c512 五种子 | 98 | 8.229 秒 | 1140.7 MiB |
| HRNet-W48 seed101 | 99 | 3.944 秒 | 1350.3 MiB |
| Mask2Former Swin-T seed42 | 100 | 7.673 秒 | 1573.4 MiB |
| M6 fold1 | 101 | 6.098 秒 | 1623.5 MiB |

这是单张原图的功能验收，内存为进程累计峰值，不能作为各模型独立峰值或平均速度比较。

PBT c512、HRNet、Mask2Former 在同一切面上完成独立张量预处理及原架构前向对照，预测像素一致：[记录](../output/cpu-model-verification.json)。c384 五份权重也已实际加载并在 CPU 上运行，对照像素一致：[记录](../output/c384-cpu-verification.json)。M6 复用现有冻结部署预测器并完成真实推理；没有重新评定其是否最优。本轮结果不是分割精度评估。

## 验证边界

- 1000 张实测使用小型有效图像，源文件合计约 109KB；另验证了约 12.6MB 的真实分块续传。5GB 上限已校验，尚未进行整批 5GB 满载压力测试。
- 移动端为真实 Edge 浏览器的手机尺寸模拟；未把它称为实体手机或 Safari 真机验收。本地地址目前绑定 127.0.0.1。
- 原尺寸轮廓内缩、孔洞、小连通区域有像素回归；未组织独立标注人员进行大规模人工复检研究。
- 导入暂存文件保留以支持失败重试；没有添加自动清空或自动删除策略。
- 未训练新模型，未依据最终测试集选种子，未发布线上，也未更新桌面端或小程序。
