# 本地 Web 全站功能与用户体验审查

日期：2026-11-03。对象：测试时本地工作树，基线见 runtime/git-baseline.json；本报告不代表线上版本或测试后变化的代码已完成验收。

## 结论

核心业务链路可运行，但不建议依据本轮结果认定为面向公众的成熟产品。主要阻断点是共享越权、会话失效不完整、原预测可直接改写及手机复检空间不足。共整理26项发现（P1 9、P2 16、P3 1）；其中既有实测缺陷，也有明确标识的代码风险及产品建议，不能把总数当作已复现缺陷数。

## 用户体验与操作减负

新手：游客入口缺样本形成死路；联系页以科研合作为主，缺少任务帮助。优先提供授权样例、上传质量说明、模型预测与人工复检的区别及失败恢复办法。

熟练用户：现有连续复检自动下一张可用，模板能减少重复配置；但草稿重复提示、错误脏标记、设置切分类丢输入增加额外操作。优先修这些摩擦，再增加快捷操作。主链路观察到至少需上传入口/方式选择、选图、创建任务、结果复检、保存/确认和导出配置等操作；本轮没有受控用户计时，不编造平均耗时或完整点击基准。

手机：390×844编辑器统计和保存面板占据主体，可视画布MAIN仅约36px；建议画布占主区、统计折叠为抽屉。真实触控手势仍未实测，touch-action仅列代码风险。

参考标准只用于评价方法，不构成合规认证：[W3C目标尺寸说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)强调触控目标与间距；[GOV.UK错误信息](https://design-system.service.gov.uk/components/error-message/)强调告诉用户具体问题与修正办法；[CVAT编辑器导航](https://docs.cvat.ai/docs/annotation/annotation-editor/navbar/)用于参照保存、导航和复检入口。是否增加能力仍依据本产品用户任务决定。
