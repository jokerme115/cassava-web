# 设计系统基线（HeroUI 口径 · 冻结版 2026-10-27）

> 状态：**冻结**。后续逐页对齐只允许「向本文件靠拢」，不允许再引入新主色、新圆角档位、新阴影。
> 依据：现有 `src/index.css` 的 HeroUI token + 本次实测的对比度数据。
> 冲突处理原则：`src/tailwind.config.js` 里的 Liquid Glass 体系（`ramp(#0a84ff…)`、`glass`、`backdropBlur 28px`、`borderRadius glass 28px`）**全部退出主路径**，仅允许在需要 blur 的少数浮层内保留局部模糊，且不得携带第二主色。

## 3. 页面骨架（全站统一，三类之一）

```
┌─ 顶栏 Header（固定，64px，白底 + 底部 hairline）──────────────┐
├─ 页头 PageHeader（页面内第一块，白卡或通栏）─────────────────┤
│   左：标题 + 一行副标题（可选）   右：主操作按钮（最多 1 主 1 次）│
├─ 内容区 Content ───────────────────────────────────────────┤
│   [左侧栏 240/280px]  [主区 flex]  [右栏 320/360px]         │
└──────────────────────────────────────────────────────────┘
```

- **类型 A（数据页：图片管理 / 结果中心 / PPD 预测）**：左栏 + 主区（+ 右栏）。
- **类型 B（表单/列表页：任务中心 / 权限管理 / 审计）**：页头 + 单列内容卡。
- **类型 C（营销页：首页 / 联系我们）**：通栏区块，无序章左栏。

硬规则：
1. 页面标题**必须**在 `PageHeader` 内，不允许出现「某页标题在卡内、另一页在卡外」（当前 PPD 预测页即违反）。
2. 一个页面只有**一个主按钮**（fill 主色）；其余动作必须是 secondary/ghost。
3. 左栏在 <768 收起，**必须提供抽屉入口**（当前图片管理页无入口，左栏功能不可达）。
4. 右栏在 <1024 移到主区下方或抽屉，不得挤压主区至 <480。

## 4. 组件状态矩阵

每个交互组件必须实现全部 6 态，缺一即视为未完成：

| 组件 | default | hover | focus-visible | active | disabled | loading |
|---|---|---|---|---|---|---|
| Button（primary） | `--brand-fill` 底 / 白字 | `--brand-fill-hover` | 2px `--brand-text` 外环 + 2px offset | 底色再深 8% | `--surface-sunken` 底 / `--muted-light` 字 / 禁点 | 左侧 16px spinner + 文案保留（不塌宽度） |
| Button（secondary） | 白底 / `--hairline-strong` 边 / `--ink` 字 | 底 `--surface-muted` | 同上 | 底 `--surface-sunken` | 同上 | 同上 |
| Button（ghost/图标） | 透明 / `--ink-secondary` 图标 | 底 `--surface-muted` | 同上 | 底 `--surface-sunken` | 图标 `--muted-light` | spinner 替换图标 |
| Input / Select | 白底 / `--hairline` 边 / placeholder `--muted-light` | 边 `--hairline-strong` | 边 `--brand-text` + 2px 外环 | — | 底 `--surface-sunken` | 右侧 spinner |
| Checkbox / Radio | 未选 `--hairline-strong` 边 | 边 `--brand-fill` | 外环 | — | 整体 40% 透明 | — |
| 卡片（可点） | 白 / `--shadow-card` | `--shadow-float` + 上移 1px | 外环 | — | 不可点则不加 hover | skeleton 占位 |
| 状态胶囊 | `*-soft` 底 / `*-text` 字 / 12px | 不变 | 外环 | — | — | — |
| 表格行 | 白 | `--surface-muted` | 行外环 | — | — | 行内 skeleton |
| 空态 | 图标 + 一句说明 + 一个主操作 | — | — | — | — | — |
| 错误态 | `--danger-text` 图标 + 原因 + 「重试」 | — | — | — | — | — |

补充：
- **纯图标按钮必须带 `aria-label`**（当前全站 94 个无名按钮）。建议收敛出一个 `<IconButton label="…">` 组件，`label` 为必填 prop。
- 表单控件必须 `<label htmlFor>`，不得只用 placeholder（当前 axe `label` 命中 97 节点）。
- 任何可点击的「像标签的东西」（如结果页「投票评分」灰胶囊）必须给出 hover + cursor + focus，否则改成静态文本。

## 5. 落地顺序（与计划文档对应）

1. 先删 `--radius-lg`、冻结 `tailwind.config.js` 的 glass 体系（保留文件但不再被引用）。
2. 替换两处最高危 token：`#0a84ff` → 按用途映射到 `--brand-fill` / `--brand-text`；`--muted-light` 承载文字处 → `--muted`。
3. 引入 `IconButton` 与 `PageHeader` 两个组件，逐页替换。
4. 逐页对齐：图片管理 → PPD 预测 → 结果中心 → 任务中心 → 权限管理 → 审计 → 首页 → 联系我们 → 个人中心 → 登录/注册。
5. 每页改完跑一次 `audit.mjs`（该页单独跑），对比 axe 命中数与截图，作为验收证据。

判据（全局）：`button-name` 与 `color-contrast` 两类 axe 命中归零；无名按钮探测数归零；<12px 文本归零；四档视口横向溢出保持 0。
