# 全站设置归并与流程减负调研

日期：2026-11-01。范围：本地网页版。仅调研源码和官方文档，不修改业务代码、不部署。

## 结论

优先集中“长期默认值”和可复用预设；当前操作的范围、结果版本和即时工具继续在现场可见。页面上的高级配置收进当前页面的一个入口，不要求操作中途跳转设置。减少重复选择、重复确认、等待和位置丢失，比单纯减少按钮更重要。

默认值与现场覆盖必须分开：当次修改只影响本次；用户明确“保存为默认”后才影响后续任务。历史任务及导出版本不得被新的默认值追溯改变。

## 调研依据

1. [CVAT 设置](https://docs.cvat.ai/docs/annotation/annotation-editor/settings/)按 Player、Workspace、Shortcuts 分类，将缩放行为、控制点大小等作为可保存的工作区偏好。适合借鉴“工具默认值长期保存，当次仍就地操作”。
2. [CVAT 快捷键](https://docs.cvat.ai/docs/getting_started/shortcuts/)按操作范围组织快捷键，并提供冲突提示和恢复默认。适合本项目复检快捷键集中配置，同时在按钮悬停显示键位。
3. [Label Studio 快捷键](https://labelstud.io/guide/hotkeys)支持从账号设置定制全局快捷键，也能在标注编辑器查看说明。适合采用“设置配置、现场查看”的双入口。
4. [NN/g：Progressive Disclosure](https://www.nngroup.com/articles/progressive-disclosure/)建议首层展示高频选项、低频选项按需展开；频繁操作不应被埋入二级入口。适合本项目统一“更多参数”，而不是把所有东西塞进设置。

上述为设计借鉴，不代表相关产品的所有团队或审核功能均属开源免费能力，本轮不涉及拉取替换项目。

## 推荐放入设置的内容

### 1. 图片与列表

- 默认网格/列表、缩略图尺寸与信息密度；默认显示分辨率、拍摄时间等字段。
- 默认排序字段/方向、默认分组方式及每页条数。四个工作区共用相同控件与规则，可按页面保存不同值。
- 设置中可管理命名的常用视图，如“按拍摄时间”“待复检”；主页面提供简短的视图切换入口。
- 原有当前目录、页码、滚动、筛选恢复应自动完成，不建议做一串可关闭的开关。

主页面保留搜索、目录、选择、上传和分页；低分辨率标识保留，信息密度不能隐藏必要质量提醒。批次实际选择范围不存为全局偏好。

### 2. 导入默认行为

- 文件夹/压缩包默认归档方式、默认保留内部层级。
- 如需要批量命名，做可预览的命名预设，默认关闭自动改名。
- 目标仍优先当前可写目录，虚拟视图沿用最近可写目录，不增加一个覆盖所有页面的全局上传路径。

本批名称、最终路径和目录冲突在原归档面板解决。精确查重保持“同最终目录、原字节 SHA-256、相同跳过、同名异内容编号”的统一规则，不开放覆盖历史文件的快捷默认值。

### 3. 预测预设

- 默认模型/命名的预测预设、任务自动命名格式、默认显示的模型收藏。
- 传统可调模型的常用配置放入预设编辑器；模型改变后按其能力显示适用项。
- 页面显示实际模型与协议、图片数量和开始按钮；任务名自动生成，点开才修改。
- “更多参数”保留当前任务的覆盖入口；保存为默认单独明确操作。

冻结模型按注册表协议执行，不能因个人设置更改分辨率或预处理，不能不可用时自动改用其他模型。任务创建时保存完整有效参数与预设版本，后续修改预设不影响历史任务。

### 4. 人工复检与快捷键

- 已有画笔/顶点/透明度继续保留为默认值，现场工具弹层也保留即时调节。
- 增加初始图层可见性、背景压暗、进入图片时适应窗口/保留视角。
- 可选“完成复检后自动下一张”“跳过已复检”，但当前复检队列范围必须现场可见。
- 快捷键集中配置，提供冲突检测、浏览器保留键提示和恢复默认；现场仅保留“?”速查。

不得把保存修订自动解释为完成复检。可在草稿落盘可靠且无未应用选区时减少重复弹窗；草稿失败、选区未应用、版本冲突仍要阻止静默丢失。不能取消必要的草稿保护作为“提速”。

### 5. 导出模板

- 模板的新建、编辑、复制、删除、默认选择集中到设置；内容随账号同步，带模板版本。
- 模板包括主体/病斑颜色、线宽、填充、透明度、PPD 字号、列数、留白、输出尺寸与常用打包内容。
- 导出弹窗首层仅显示范围/数量、版本来源、模板、格式和预览；“调整本次样式”展开低频设置。
- 模板删除或在别处不可用时明确提示，让用户选择参考样式，不静默换图样。

实际导出范围、当前/历史结果版本、预览必须现场确认。默认“最新人工修订优先”可保留，但来源应可见；导出启动后固定快照。PPD 的面积口径不是个性化视觉设置。

## 推荐设置导航

继续沿用现有侧栏与工作区视觉，不增加新的首页卡片。普通用户按需求逐步增加“图片与列表、导入默认、预测预设、复检与快捷键、导出模板”，以页面为粒度保存和恢复默认。账号资料/安全保持独立。管理员的账号、角色、站点、日志、访问统计仍放管理分组。

不要新增无实现的通知、全站暗色、自动清理、缓存加速等开关。只有已经连接实际消费者、保存、异常和权限隔离的设置才能上线。

## 页面最终应保留的首层操作

| 页面 | 首层保留 | 二级入口 |
|---|---|---|
| 图片管理 | 目录、搜索、图片选择、上传、分页 | 视图选项、选择后出现的批量操作 |
| PPD 预测 | 左侧选图；右侧预设/实际模型、数量、开始 | 本次参数调整、模型来源详情 |
| 任务中心 | 搜索/状态、进度、查看结果；运行中显示取消 | 参数详情、日志、历史管理 |
| 结果中心 | 搜索/复检筛选、图片、预览、复检、导出 | 统计分布、模型/版本详情 |
| 复检编辑器 | 画布、图层/工具、撤销重做、保存/完成、切图 | 工具弹层、快捷键速查、历史版本 |
| 导出弹窗 | 范围和数量、版本、模板、格式、预览 | 本次样式调整、进入模板管理 |

范围筛选、版本选择、删除确认、运行状态不藏入设置。删除/批量操作没有选中内容时不占据整排工具栏，选中后在固定选择条中出现。

## 连续流程与技术减负

- 从图片管理进入预测自动携带目录/选择；预测完成进入该任务结果；复检返回保留筛选、页码与滚动。现有已有部分传递，后续应补完整验收，不另做一套状态。
- 普通浏览默认进入分割预览，只有明确“复检”才打开编辑器。
- 复检在相同队列中切图并保留约定视角，预加载相邻图片；原尺寸掩码仍需正确加载，不能为动画快而降低计算精度。
- 搜索可采用约 250–350ms 防抖、请求取消和最后请求生效；筛选改变重置页码，保留可见筛选条，提供一键清除。
- 列表与统计采用同一条件，局部更新成功项，不在每次操作后整页闪白；失败项保留选中和重试入口。
- 权限/角色读取共享，导入轮询按活动状态调整，预览请求复用缓存和取消失效请求。以上均由系统处理，不增加用户设置负担。
- 动画采用短暂淡入或状态过渡；后台绘图、列表渲染与网络等待应分别分析，不能拿动画代替响应优化。

## 实施优先级和验收

第一批：补齐分组记忆；列表默认值；预测预设；导出快捷层与账号模板。目标是默认配置可完成“选图→预测”和“选范围→导出”，不必往返设置。

第二批：连续复检、视角/图层偏好、快捷键、跨设备同步与模板版本。草稿、保存修订和完成复检的语义不合并。

第三批：对实际请求与大列表做测量，合并重复请求、调整空闲轮询、预取下一张。测量前不报告具体性能收益。

验收至少覆盖：新旧账号默认值、跨设备同步、关闭再打开浏览器、临时覆盖不污染默认、预设不改变历史任务、冻结模型不被覆写、模板缺失提醒、筛选/分页/导出一致、跨页连续切图、草稿失败与版本冲突、手机可操作。

本轮完成到“有来源、有源码位置、有归属边界和实施顺序的建议”即止，不扩展到实现新设置或线上操作。
